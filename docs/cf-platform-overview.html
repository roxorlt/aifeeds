二、下一步真该评估的 — 4 个产品

每个都有明确的业务切口，不是「可能能用」级别的虚词。

产品定位你的业务怎么吃下
AI Gateway LLM 调用 proxy（缓存 / analytics / fallback） 5 分钟接入 ROI 最高。DeepSeek 调用全走 Gateway：(a) 同 prompt 自动缓存（is_relevant 判别同推文几小时内会重复 score 多次）；(b) 全套 QPS / latency / cost analytics；(c) 配 fallback（DeepSeek 挂自动切 Workers AI / OpenAI 兜底）。几乎纯收益
Vectorize 向量数据库（embedding + ANN） 三个直接场景：(a) 跨源去重（X/GH/PH 同一个产品，文本 embedding 相似度 > 0.85 合并）；(b) 语义搜索（dashboard 加搜索框，"最近 AI agent 框架" → 真相关 item，不只关键词）；(c) 类似项目推荐（GH drawer 加 "Related repos"）
Queues 持久消息队列（producer/consumer） 解耦 scraper / classify / translate / enrich：当前 */5 cron 串行调用，translate 慢就阻塞别的；迁 queue 后 scraper push → consumer 异步处理，吞吐 + 失败重试都白送
Workflows 持久多步流程（sleep / retry / 状态自动持久化） PR7 newsletter 完美场景：每周触发 → 拉所有订阅用户 → 每个用户拼摘要 → 发邮件 → 失败自动 retry。手写 cron 要自己处理状态、断点续跑；Workflow 直接搞定。也适合 PH 单产品页深度抓取这类多步异步 pipeline

三、有特定场景出现时再考虑 — 5 个产品

不是不能用，是「现在做没意义，等触发条件出现再回头看」。

产品定位你业务的潜在切口
Workers AI CF 自家 LLM 推理（开源模型 / 边缘运行） 替代 DeepSeek 做 is_relevant 二分类 / embedding 生成。@cf/baai/bge-base-en-v1.5 做 embedding 几乎免费。但中文翻译 / 复杂判断仍 DeepSeek 强
Images 边缘图片变换（resize / format / quality） PH/GH/X 抓回的封面图，前端按设备宽度动态请求 cdn-cgi/image/width=400,format=webp，移动端瘦身 60%+。但你已有 R2 + /r/<key>，迁移有 cost
Email Routing 入站邮件转发（user@ai-feeds.com → Gmail） support@ / unsubscribe@ai-feeds.com 转你 Gmail；newsletter 退订链接走专用收件地址，落地处理省事
Web Analytics 真实用户性能监控（LCP / FID / 错误率） 10 分钟开关，免费。telemetry SDK 已埋 Web Vitals 但只落 D1；Web Analytics 给完整 UI 看分位数 + 设备分布 + 路由级 latency
Workers Logs / Logpush 日志聚合 / 落 R2 / 推外部 SIEM wrangler tail 已是 dev 调试用。Logpush 推 R2 适合 90 天后 events 表满了想抽样存档分析，或 PR6 「异常告警分级」从 logpush + ETL 出
暂不必

四、明确不必投入精力（但解释为什么）— 5 个产品

别被 CF marketing 拉走注意力，这些跟你业务模型不匹配。

产品定位不用的理由
Hyperdrive Postgres 连接池 你用 D1（SQLite），用不上。除非未来数据量 / 并发突破 D1 上限
Durable Objects 强一致 + 有状态分布式对象 chat room / 实时协作场景。你业务是「写一次读多次」内容流，D1 + KV 完全够，DO 是 over-engineering
Stream 视频托管 + HLS 转码 你只抓 X/PH 的 video URL 直链，不自己做 video 服务
Containers Docker 镜像 runtime（公测中） 理论可替代本地 browser-use Python scraper，但限制多（CPU 时长 / 启动慢 / 价格 vs 本地白嫖）。等 GA 再看，你本地 cron 跑得很好
Workers for Platforms 让你的用户在你 Worker 里跑他们自己 Worker Shopify Functions 类多租户场景。你不是平台

👉 我会推荐的下一步顺序

  1. AI Gateway 包 DeepSeek（半天）— 省 20-30% 重复调用成本 + 全套 analytics 白送 + fallback 防 DeepSeek 挂
  2. Vectorize 做跨源去重 + 语义搜索（2-3 天）— 直接给 dashboard 加产品力，"AI agent 框架" 搜出真相关结果
  3. Web Analytics 开关（10 分钟，免费）— 补 telemetry SDK 短板，看 prod 真实分位数

本文档基于 2026-05-06 业务现状生成；CF 产品矩阵会变动，半年后回头复核一次。
