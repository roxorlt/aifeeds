Metrics 样式对比

目标：明示这是 X 平台的转评赞数据，不是 ai-feeds 的可交互按钮。 每张卡同一条推文，区别只在底部 metrics 区。把鼠标悬停到 metrics 上观察「是否还像可点的按钮」。

现状 完全照搬 X 的 hover halo
127 46 823 12.4K

⚠️ hover 出 pastel 背景 + 文字变色，和 X 原生按钮几乎一致 → 用户预期点击会 reply/RT/like

方案 A 极简：去 halo 去圆形 + 「来自 X」
127 46 823 12.4K 来自 X

优点：最克制；icon 缩小、纯灰、无 hover；右边 X logo + 「来自 X」点出来源。 缺点：原本 metrics 占主视觉，现在被压得有点过弱。

方案 B 中庸：保留 icon 大小、去 hover、加 X 标签
X 数据 127 46 823 12.4K

优点：「X 数据」徽标第一眼就告诉用户「这是引用，不是按钮」，metrics 视觉权重保留。 缺点：徽标占左边一格，整体略拥挤；徽标和 metrics 高度对齐需要微调。

方案 C 收成元信息行：小字、灰色、行内 dot 分隔
X 数据 · 127 回复 · 46 转推 · 823 点赞 · 12.4K 阅读

优点：彻底脱离按钮语义，作为「元信息」呈现，类似文章底部的「字数 · 阅读时长」。 缺点：信息密度高、字号小，扫读时不如方案 B 显眼；视觉层级降级最明显。

我的推荐
  • 方案 B 综合最稳：「X 数据」徽标第一眼就解决「这不是按钮」的认知问题， 同时保留 icon 视觉权重让用户能扫到大致量级。
  • 方案 C 适合后续 dashboard 整体走「资讯阅读」气质（放弃社交感）的方向， metrics 完全降级为元信息。如果 List 数据需要做「热度排序」之类操作，C 视觉太弱反而不利。
  • 方案 A 视觉最克制但右上角「来自 X」的 affordance 信号弱， 不如 B 的徽标显眼，可能还是会有人误点。
