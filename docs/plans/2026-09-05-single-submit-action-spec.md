# 补录只留一个提交动作 · 规格（2026-09-05）

> **owner 9/5 早的实际遭遇**：08:29 与 08:30 提交两条线索，都 `failed / processing_retry_exhausted`，失败详情 `search_public:trusted_gateway_http_502`。而同一天我用直接录入通道测的三条（08:44 / 11:29 / 11:33）全部成功入池。
>
> **差别**：页面上现在并排放着两个提交按钮，owner 点的是原有的「提交并授权核验追加」（走完整核验：搜索 → 抓正文签名 → 两轮大模型核验），第一步搜索就 502——那条路用的是需要密钥的提供方，密钥全缺。新加的「我确认，直接加入」不需要密钥，能成。
>
> **这是设计失误**：把一个在本部署里注定失败的动作摆在第一位，还要 owner 自己分辨该点哪个。owner 要的是「把这条新闻加进去」，不是选择技术路线。

## 1. 目标

**补录表单只有一个提交按钮**。点下去之后：

1. 先按现有核验通道尝试（搜索 → 取证 → 核验）。成功则照旧，候选带完整签名证据入池。
2. 核验通道任一步失败（搜索无提供方、取证 502、评估不过），**自动降级为 owner 断言入池**，用 owner 写的那句话作标题与卡片文字，绝不空手而归。
3. 无论走哪条，入池后都跑背景素材补取（有链接抓该链接 + 按描述搜索；无链接只搜索），素材只进口播的补充材料，不改卡片文字。

owner 从头到尾只做一个动作，看到的只有「已加入候选池」以及这条候选是「已核验」还是「你担保的」。

## 2. 不可动的边界

- 入池不被取材/核验阻塞（9/4 上午修复的核心）。
- 降级入池走的仍是既有 `owner_asserted_v1` 通道，签名 proof、正式新闻门、sanitize 稳定性等一概不变。
- 不覆盖 `extra.ai_summary_zh`，不碰被正式新闻门绑定的列。
- 已核验成功的线索**不得**被降级覆盖。

## 3. 实现

### 3.1 云端

- `POST /api/digest/daily-news-leads` 新增可选 `fallback_to_owner_asserted: true`（页面固定传）。语义：核验通道最终失败时，服务端自动以 `statement`（缺省取 `text` 规范化结果）走 `owner_asserted_v1` 入池。
- 降级的判定点在核验流程走到终态之后：线索落到 `failed`，或落到 `needs_review` 且无可用评估。此时若该线索带 `fallback_to_owner_asserted` 且未确认，则执行一次担保入池。
- 降级必须幂等：同一线索只降级一次，已确认的不再处理。
- 降级后线索的 `candidate_authorization` 为 `owner_asserted_v1`，并在审计里记明是「核验失败后自动降级」（`metadata_json` 带 `fallback_from` 与原 `error_code`），便于事后分辨哪些候选是自动降级来的。
- 详情 DTO 增加 `fallback_applied: boolean`，供页面标注。

### 3.2 面板页面

- 补录表单**只保留一个按钮**，文案「提交并加入候选池」。移除「我确认，直接加入」与「提交并授权核验追加」两个并列按钮。
- 提交体固定带 `fallback_to_owner_asserted: true` 与 `statement`（取文字线索的规范化结果，规则同既有陈述校验）。
- 提交后的状态文案分三档：核验成功「已核验并加入候选池」；降级成功「未能找到公开来源，已按你写的这句话加入候选池」；两者都失败才报错。
- 卡片标注：`candidate_authorization === 'owner_asserted_v1'` 且 `fallback_applied` 为真时标「你担保的（自动降级）」；非降级的直接录入标「你担保的」；核验通过的不标。
- 素材为空的提示保留（口播只能依据那一句话）。

## 4. 测试

- 核验成功时不降级（计数桩证明未调用担保写入）。
- 核验失败（模拟搜索 502）时自动降级，线索 `confirmed_at` 非空、`candidate_authorization` 为 `owner_asserted_v1`、审计带 `fallback_from`。
- 降级幂等：重复触发只入池一次。
- 已确认线索不被降级覆盖。
- 降级后正式新闻门仍 `ALLOW_VERIFIED_MANUAL`、连续两次 sanitize `changed:false`。
- 陈述不合规时降级不执行，返回明确错误而不是静默丢失。
- 页面：只有一个按钮；三档文案各一条用例（真实文件切片方式）。
