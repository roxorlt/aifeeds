README

Self-Improvement Skill

将学习与错误记录到 markdown 文件以实现持续改进。后续编码 agent 可处理这些条目生成修复方案，重要的学习会晋升到 project memory。

首次初始化

记录任何内容前，确保 .learnings/ 目录及文件存在于项目或 workspace 根目录。如缺失则创建：

mkdir -p .learnings
[ -f .learnings/LEARNINGS.md ] || printf "# Learnings\n\n..." > .learnings/LEARNINGS.md
[ -f .learnings/ERRORS.md ] || printf "# Errors\n\n..." > .learnings/ERRORS.md

↑ 代码块按规则保留英文原文不翻译

勿覆写已存在文件。如目录已初始化，此操作无副作用。不要记录 secrets、tokens、private key、环境变量或完整源/配置文件，除非用户明确要求该详细程度。
