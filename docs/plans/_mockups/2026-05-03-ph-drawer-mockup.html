Zed 1.0 是一款主打 极致性能 + AI 协作 的下一代代码编辑器。 相比 VS Code / Cursor，Zed 强调原生体验（Rust 实现）、极简界面、 多人协同实时编辑。本次 launch 是首次正式版发布，社区反馈集中 于"轻、快、设计克制"，缺点是扩展生态较弱。值得关注的"以代码体验 为本位"的 AI 编辑器代表。
