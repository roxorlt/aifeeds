介绍 GPT-5.5：更强的推理与更低的延迟

Introducing GPT-5.5: stronger reasoning, lower latency
ELI25 摘要

这是 OpenAI 最新的旗舰模型，简单说就是比上一代更会“想问题”——遇到复杂任务时它会自己多想几步再回答，同时响应速度还更快了。对开发者最实在的变化是 API 价格降了三成。

封面 og:image · 经质量门控（ar>2‖ar<0.5‖maxDim<240 滤低质）+ R2 缓存

正文

主要变化

GPT-5.5 在复杂推理任务上比 GPT-5 有明显提升，尤其是多步数学、代码调试和长文档分析这三类场景；它会在内部先规划再作答，而不是一上来就给结论。

  • 推理更深：遇到难题时自动展开多步思考，必要时回头检查自己的中间结论。
  • 延迟更低：相同任务下首字延迟（time-to-first-token）平均下降约 40%。
  • 价格更低：API 输入价格下调 30%、输出价格下调 20%。

开发者如何接入

把模型名改成 gpt-5.5 即可，接口保持兼容：

from openai import OpenAI
client = OpenAI()

resp = client.responses.create(
    model="gpt-5.5",
    input="Explain quantum entanglement in one sentence",
    reasoning={"effort": "high"},
)
print(resp.output_text)
注意：reasoning.effort 设为 high 时会消耗更多推理 token，建议只在确实需要深度思考的任务上开启。

定价对照

档位 输入（每百万 token） 输出（每百万 token）
GPT-5$2.50$10.00
GPT-5.5$1.75$8.00

更多迁移细节见官方文档；旧模型在过渡期内仍可继续调用，查看迁移指南。

What's new

GPT-5.5 shows a clear jump over GPT-5 on multi-step reasoning — especially multi-step math, code debugging, and long-document analysis. It plans internally before answering instead of replying in one pass.

  • Deeper reasoning: expands several thinking steps on hard problems and re-checks its own intermediate results.
  • Lower latency: time-to-first-token drops ~40% on the same task.
  • Lower price: API input price −30%, output price −20%.

How to integrate

Change the model name to gpt-5.5; the interface stays compatible:

from openai import OpenAI
client = OpenAI()

resp = client.responses.create(
    model="gpt-5.5",
    input="Explain quantum entanglement in one sentence",
    reasoning={"effort": "high"},
)
print(resp.output_text)
Note: setting reasoning.effort to high consumes more reasoning tokens — enable it only for tasks that truly need deep thinking.

Pricing

Tier Input (per 1M tokens) Output (per 1M tokens)
GPT-5$2.50$10.00
GPT-5.5$1.75$8.00

See the docs for migration details; older models remain callable during the transition, read the migration guide.
