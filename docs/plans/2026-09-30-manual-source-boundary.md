# 补录指定链接取材边界修复

## 目标与范围

9 月 29 日 AMD 收购 World Labs 线索的微信 URL 返回验证码页，补充检索召回 Atlas 发布报道，起草结果替换了原事件。本次仅修复指定链接路径的取材边界；不重做视频、不修改历史记录、选题评分、数据库结构、签名或鉴权。

## 风险与不变量

这是涉及内容完整性的高风险修复，范围限于补录流水线。外部网页、跳转和搜索结果不可信；用户给定的链接是取材边界，人工线索不是已经独立核实的事实。

- 有 URL：仅使用该链接可用正文，不运行替代文章搜索，也不把搜索材料混入有效正文。
- 正文为空、获取失败、明确登录/验证码墙：不分析或生成墙文本，不保存它为正文/证据；保留既有 owner-asserted 线索入池能力并给出具体缺失原因，material tier 为 none。
- 不修改既有 owner-asserted 授权、签名与安全抓取控制；不绕过登录或验证码。
- 正常文章提及验证码、登录功能不能仅凭关键词被拒绝；正常 URL 跳转保持兼容。
- 纯文字入口保持现有行为。本次不声称解决所有无链接检索的事件判定问题。

## 验收

先红后绿覆盖：AMD/World Labs 验证码 URL + 无关 Atlas 搜索桩不被调用；空/抛错/登录墙/验证码墙不进入生成与证据；正常链接只用原文；正常正文讨论登录/验证码不误伤；纯文字仍可检索。验证 durable workflow 与 entry 的 fallback/detail 传递，运行受影响测试与类型检查。最终由一名独立 reviewer 审查当前差异和上述失败路径，不扩展成架构重构。

## 交付边界

在隔离 cdx 分支开发；原主工作树不变。修复验收后用户已明确授权合版上线，走 PR 检查与现有 main CI 发布路径。无迁移，不部署 HK/腾讯视频服务，不改历史数据；发布结果以 PR 与 Deploy Worker 运行记录为准。
