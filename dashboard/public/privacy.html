隐私政策

最后更新：2026-05-02

我们是谁

AI-Feeds（ai-feeds.com）是一个独立开发者项目，由个人维护，提供一站式 AI 信息聚合看板。

我们收集哪些信息

  • device_id（匿名访客标识）：首次访问时本地生成的随机字符串，存在你浏览器的 LocalStorage 里。不读取设备硬件信息，不形成"设备指纹"。
  • IP 地址 / 浏览器 User-Agent / Referer：每次请求自动记录，用于防刷、地域统计、安全审计。
  • 手机号（仅注册/登录后）：用于唯一身份验证，仅在登录流程中使用，存储为不可逆方式或脱敏显示。
  • 验证码（hash 后）：登录流程，仅校验用，明文不入库。
  • 行为事件（浏览、点击、停留时长、性能指标、错误日志）：通过 events 表统一收集，不包含手机号或敏感个人信息。

我们使用哪些第三方服务

  • Cloudflare Turnstile：人机验证（防刷），不收集敏感信息。
  • 腾讯云 / PushDeer：发送短信验证码（依实际后台配置）。
  • Cloudflare Workers / D1 / Pages / R2：数据存储和服务托管。

用户控制权

  • 清除浏览器缓存即可重置 device_id（你浏览器主导）。
  • 设置页可主动「退出登录」「退出全部设备」「注销账号」。
  • 注销账号会立即清空 PII 字段，identity 哈希后保留以避免引用丢失。

政策变更

政策变更时，我们将在本页面更新「最后更新」日期。重大变更会在登录后的 dashboard 顶部提示。
