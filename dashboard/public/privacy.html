隐私政策

最后更新：2026-05-02 · 生效日期：2026-05-02

AI-Feeds（ai-feeds.com，以下简称"本服务"）由独立开发者运营，提供 AI 行业信息聚合看板。本政策说明我们收集哪些信息、为什么收集、如何使用、如何保护，以及你拥有哪些选择权。

使用本服务即表示你已阅读并同意本政策。请你在使用前仔细阅读，对其中重要内容（粗体或下划线标注）做合理理解。

一、我们是谁

AI-Feeds 是个人维护的项目，运营主体为独立开发者，不属于任何公司主体。本政策中"我们"指本服务的运营者。

二、我们收集哪些信息以及为什么收集

2.1 你访问时自动收集

信息用途是否必须
device_id（匿名访客标识，本地生成 21 字符随机字符串，存在浏览器 LocalStorage）区分访客做去重统计、行为埋点、防刷计数必须（清缓存即重置）
IP 地址 / User-Agent / Referer防刷、地域统计、来源分析、安全审计必须（HTTP 协议自带）
浏览行为事件（页面访问、卡片曝光、点击、停留时长、滚动深度、性能指标 LCP/INP/CLS、JavaScript 错误）了解用户使用情况优化产品；定位前端 bug必须

我们不收集的：设备硬件信息（IMEI / MAC / 传感器列表）、浏览器指纹（canvas / WebGL hash）、第三方 cookie、定位坐标、通讯录、相册。

2.2 你登录后才收集

信息用途是否必须
手机号身份验证、登录凭证、安全告警通知（仅自己）登录必须
验证码（哈希后）验证 + 短期防刷计数登录必须
session token（cookie）保持登录状态登录必须
昵称 / 头像（可选填）展示非必须
收藏 / 订阅 / 阅读偏好（未来功能）个性化体验非必须

2.3 短信验证码

登录时我们会通过短信服务（腾讯云短信 / 紧急情况下经 PushDeer 发到管理员设备转发）向你的手机号发送 6 位数字验证码。验证码有效期 5 分钟，错误超过 5 次会临时锁定账户 30 分钟。验证码本身在数据库中以 SHA-256 哈希形式存储，明文不会落库。

三、信息如何存储与保护

3.1 存储位置

本服务的数据库（D1）和静态资源（Pages / R2）托管于 Cloudflare 全球分布式节点。这意味着你的数据可能存储在中国大陆境外的服务器（包括但不限于美国、欧洲、亚太地区其他国家）。本服务采取业界标准的传输加密（HTTPS）和访问控制，但无法对你网络环境之外的传输路径做绝对保证。

请注意：登录注册即表示你理解并同意，你提供的手机号、登录凭证、行为日志可能出境到 Cloudflare 全球节点存储。如不接受，请停止使用本服务。

3.2 保留期限

  • device_id（本地）：直到你清除浏览器缓存
  • 行为事件 events：保留 30 天后自动清理（cron 删除）
  • 短信日志 sms_send_log：保留 30 天后自动清理
  • session：30 天滑动过期，主动登出立即撤销
  • 用户主体（users）+ 身份凭证（identities）：账号有效期内保留；注销后立即清空昵称、头像，手机号哈希后保留以避免引用丢失

3.3 安全措施

  • 验证码 SHA-256 加盐哈希存储
  • session cookie 标记 HttpOnly（JavaScript 不可读）+ Secure（仅 HTTPS）+ SameSite=Lax
  • 多层防刷：Cloudflare Turnstile 人机验证 + 三维度限流（手机号 / IP / 设备）+ 每日全局额度上限
  • 错误率 / 异常 IP 实时告警到管理员

四、信息如何共享

我们不出售你的个人信息。在以下有限场景才会共享：

  • 必要的服务提供商：Cloudflare（基础设施）、腾讯云短信 / PushDeer（短信通道）、DeepSeek（AI 翻译，仅处理公开内容，不传你的 PII）
  • 法律要求：依据有效法律程序（生效法律法规、政府要求、司法令状）必须披露的情况
  • 注销账号后的匿名化数据：行为统计可能在去除可关联到你的字段后保留用于产品分析

五、你的权利

你可以随时：

  • 查询 / 复制当前账号信息（在「设置」页可见昵称 / 脱敏手机号 / 创建时间）
  • 退出登录（撤销当前会话）或退出全部设备（撤销所有会话）
  • 清除本地标识（在「设置 → 数据」点击"清除本地浏览器标识"会重置 device_id）
  • 注销账号（在「设置 → 危险区」点击"注销账号"，输入完整手机号确认后，账户立即不可登录，PII 字段清空）
  • 需要导出全部数据 / 撤回同意 / 投诉处理结果，发邮件到 ltsms86@gmail.com，我们会在 15 个工作日内回复

六、Cookie 与本地存储

本服务使用以下技术：

  • LocalStorage：存 device_id、telemetry 队列缓存、登录态等。可在浏览器设置中清除。
  • SessionStorage：存当前会话临时数据。关闭标签页即清。
  • HTTP Cookie：仅一项 xlist_sid，用于登录状态保持，HttpOnly 标记。退出登录即清。
  • 本服务不使用第三方追踪 Cookie（如 Google Analytics、Facebook Pixel 等）。

七、未成年人保护

本服务面向 14 周岁以上用户。我们不会主动收集未成年人个人信息。如发现未成年人未经监护人同意提供个人信息，请通过下方邮箱联系我们，我们会立即删除相关信息。

八、政策更新

本政策会随产品功能调整而更新。重大变更（涉及收集类型或共享范围）会通过 dashboard 顶部公告或邮件（如已绑定）提醒你重新同意。次要变更仅更新顶部"最后更新"日期。建议你定期回看本页面。
